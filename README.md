# MM Flight Analyzer – Web-App

> Inoffizielles Werkzeug, nicht mit dem Hersteller von Ethos oder Jeti verbunden. Ethos und Jeti sind Marken ihrer Inhaber.

Wertet Flüge aus Telemetrie-Logs von Ethos- (CSV) und Jeti-Sendern (.log) im Browser aus. Die Logs bleiben auf dem Gerät, es wird nichts hochgeladen.

Installieren: iPhone/iPad in Safari „Teilen → Zum Home-Bildschirm“, Android in Chrome „App installieren“. Nach dem ersten Öffnen läuft die App auch ohne Netz.

Dieses Repo enthält nur die fertig gebaute Seite (`npm run build-pwa -- --beispiel-verschoben`, Beispiel-Log mit verschobener GPS-Spur). Stand: Version 2026.10.1, Quell-Commit a1fbd9e.
