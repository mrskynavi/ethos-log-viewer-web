# Ethos Log Viewer – Web-App

> Inoffizielles Werkzeug, nicht mit dem Hersteller von Ethos verbunden. Ethos ist eine Marke ihres Inhabers.

Wertet Telemetrie-Logs (CSV) von Ethos-Sendern im Browser aus. Die Logs bleiben auf dem Gerät, es wird nichts hochgeladen.

Installieren: iPhone/iPad in Safari „Teilen → Zum Home-Bildschirm“, Android in Chrome „App installieren“. Nach dem ersten Öffnen läuft die App auch ohne Netz.

Dieses Repo enthält nur die fertig gebaute Seite (`npm run build-pwa -- --ohne-beispiel`). Stand: 1c7a8a9.
